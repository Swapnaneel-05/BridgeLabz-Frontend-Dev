Responsive CSS Cheat Sheet

Quick reference for Filters, Media Queries, Responsive Design & Typography

Filters
Example: filter: grayscale(100%);
Use filters to adjust images or elements. Combine with transitions for smooth effects.
Media Queries
Example: @media (max-width: 900px) { ... }
Media queries adapt layout and styles across breakpoints (mobile, tablet, desktop).
Responsive Design
Tip: Use flex and grid with relative units to build flexible layouts that adapt.
Typography
Example: font-size: clamp(1rem, 2.5vw, 1.25rem);
Scale type fluidly to maintain readability across devices.
Breakpoints
Common breakpoints: 1200px, 900px, 700px, 480px. Pick breakpoints based on content, not device names.
Accessibility
Ensure focus states, semantic markup, and enough color contrast. Test keyboard navigation and screen readers.
Tip: Resize the viewport to see the layout change — headings become keys and descriptions become values below 700px.
